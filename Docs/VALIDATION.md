# 验证记录

环境：Xcode 27.1，iOS 27.1 Simulator（iPhone Duo 设备类型）。记录日期：2026-09-21。

## 已完成

- 四个独立工程均通过模拟器构建，包括资源与图标。
- 对弈钟状态回归检查通过：初始状态、当前方才能交棒、按实际时间间隔扣时、暂停不扣时、继续保留当前方、手数累加、重置、时间归零。
- 鼓机使用当前 SDK 的 `connectNode` 与 `playAudio` 可抛错入口；没有沿用已弃用的对应入口。
- 源文件与新建 Git 历史的个人信息检查通过。

### 模拟器界面与交互（Duo 模拟器，通过 Device Hub 切换姿态）

- 对弈钟：闭合与展开均显示初始 03:00；基线开关切换为纵向堆叠、同向文字；适配版展开为左右分区、面对面旋转；黑方先行、当前方交棒、非当前方轻触不换人、暂停后双方时间与手数保留；合上后外屏显示同一局面（黑方 02:48 / 2 手、白方 02:50 / 1 手）。
- 折叠鼓机：四个鼓垫真实点击，敲击数 1→4、音色名随最后一次敲击变化；速度拖动到 160 BPM；开始后四拍指示前进，停止后保留敲击与速度；基线为上下堆叠；Book 姿态旋转后为上方反馈、下方鼓垫；闭合外屏保留同一状态并可见速度与开始入口。
- 掌上调色台：粗细拖动到 18 pt，绘制六笔三色；基线的工具面板覆盖画布下部，适配版画布与工具分区；Book 姿态旋转后画布在上、工具在下，笔迹按相对坐标重绘；闭合外屏保留笔迹，工具面板可滚动；撤销一笔后剩 5 笔；清空后撤销可恢复。
- 分区留白：三款 App 的 ArrangementView 主、副内容各留 12 pt，展开左右与半展开上下相邻处约 24 pt，已按最终构建重新截图确认。

## 未验证

- 真机：触感、折叠机构、性能、真实铰链角度。
- 音频：模拟器输出为 None，只确认了引擎连接与播放调用无错误，听感、延迟与长时间节拍稳定性未验证。
- 辅助功能：大字号、VoiceOver、增强对比度下的布局。
- 复杂姿态：仅验证了闭合、完全展开、Book 姿态旋转后的纵向内屏；其他角度与外接显示未测试。

模拟器截图与操作记录不等同于真机验证；公开版本仍是供学习和继续验证的 Demo。
